# Seravia

Informative site for Seravia Lifesciences — a doctor-owned skincare house formulating for Indian skin and climate.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` Home
- `/story` Founding point of view
- `/science` Formulation method and ingredient philosophy
- `/concerns` Pigmentation, acne, sensitivity, tanning, premature ageing
- `/contact` Enquiry form (confirms in the browser; inbox not connected yet)
